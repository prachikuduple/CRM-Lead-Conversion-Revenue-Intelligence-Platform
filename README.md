# Lead Conversion, Pipeline & Revenue Intelligence Platform

### CRM Analytics | Streamlit Web Application | Power BI | MySQL

An end-to-end **CRM Analytics and Revenue Intelligence project** developed to transform raw lead data into meaningful sales and business insights.

The project combines an interactive **Streamlit web application**, **MySQL database**, **Excel-based data processing**, and an interactive **Power BI dashboard with page navigation** to analyze the complete lead lifecycle — from lead generation and follow-ups to qualification, conversion, lost opportunities, pipeline performance, and potential revenue.

## Project Overview

The main objective of this project is to understand **why leads convert, where leads are getting lost, how the sales pipeline is performing, and which segments contribute to higher revenue opportunities**.

Instead of simply presenting raw CRM records, the project converts the data into interactive analytics that can help sales teams monitor performance and make more informed decisions.

## Key Features

### Streamlit CRM Analytics Web App

The Streamlit application provides an interactive interface for exploring CRM data.

It includes analysis of:

* Lead conversion performance
* Lead sources
* Lead status and pipeline stages
* Salesperson performance
* Industry-wise lead distribution
* Engagement scores
* Follow-up activity
* Response time
* Opportunity value
* Converted vs lost leads
* Revenue and pipeline insights

Interactive filters allow users to explore the data based on different business dimensions.

### Power BI Dashboard

A separate **Power BI dashboard** was created to provide a more visual and business-oriented view of the CRM data.

The Power BI report includes **multiple navigable pages**, allowing users to move between different analytical sections using page navigation/buttons.

The dashboard focuses on areas such as:

* Executive CRM Overview
* Lead & Conversion Analysis
* Sales Pipeline Analysis
* Salesperson Performance
* Revenue & Opportunity Analysis
* Lead Source and Industry Insights

The navigation-based design makes the report easier to explore instead of placing every visual on a single page.

### Data Processing

Python was used for:

* Data cleaning
* Missing-value handling
* Data validation
* Data transformation
* Analytical calculations
* Preparing data for visualization

**Pandas** and **NumPy** were mainly used for data manipulation and numerical analysis.

### Database Integration

**MySQL** was used to store and manage the structured CRM data.

The workflow follows:

Excel Dataset → Python Data Cleaning → MySQL → Streamlit / Power BI → Business Insights

## Business Insights

The project helps answer practical CRM questions such as:

* Which lead sources generate the most conversions?
* Which industries have stronger opportunities?
* Which salespersons are performing better?
* Where are leads dropping out of the pipeline?
* How does engagement affect conversion?
* Which leads have higher opportunity values?
* How many leads are converted, qualified, new, or lost?
* What are the major reasons behind lost opportunities?
* Which areas require better follow-up?
* How can the sales pipeline and potential revenue be monitored?

## Dashboard Navigation

The Power BI report uses **interactive page navigation** so users can move between different analytical views.

For example:

**Overview → Lead Analysis → Pipeline Analysis → Salesperson Analysis → Revenue Analysis**

This makes the dashboard behave more like a complete **Business Intelligence application** rather than a static report.

## Project Outcome

The project demonstrates how a CRM dataset can be converted into an end-to-end analytics solution using **Python, Streamlit, MySQL, Excel and Power BI**.

It combines data preparation, database management, web-based analytics and business intelligence into one practical project focused on **lead conversion, pipeline monitoring and revenue intelligence**.
